# React + TypeScript + Vite
## Search Result UI Clone

This project is a pixel-perfect recreation of a search results UI inspired by a Dribbble shot. Built with React, Vite, and Tailwind CSS, it demonstrates frontend design intuition and attention to detail.

### Features
- Modern search bar with live filtering
- Dynamic tabs for All, Files, and People
- Interactive dropdown filter with toggle switches
- Highlighted search matches in results
- Responsive, clean, and accessible UI
- Dummy data separated for easy updates
- Icons via react-icons

### Getting Started
1. Clone the repositoryg
2. Install dependencies with `npm install`
3. Start the development server with `npm run dev`
4. Open [http://localhost:5173](http://localhost:5173) in your browser

### Folder Structure
- `src/App.tsx`: Main UI and logic
- `src/components/Dropdown.tsx`: Reusable dropdown filter component
- `src/data/dummyResults.ts`: Dummy search data

### Deliverables
- Fully functional UI/UX matching the Dribbble reference
- Hosted demo (Netlify or similar)
- GitHub repository link
- Video walkthrough explaining design and implementation

### Design Approach
All design choices were made by visually analyzing the reference and using Tailwind CSS utilities to match layout, colors, spacing, and interactions as closely as possible.
